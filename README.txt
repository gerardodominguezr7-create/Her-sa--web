HER-SA SERVICIOS INDUSTRIALES — SITIO WEB

Archivo principal: index.html

El proyecto incluye de forma local:
- Logotipo HER-SA
- Fotografías de servicios
- Fotografías de proyectos
- Marcas de clientes en la sección Clientes
- Iconografía de WhatsApp integrada en el HTML
- Diseño responsive para computadora, tablet y celular
- Tema claro/oscuro
- Cotizador por WhatsApp

Para revisar el sitio, abra index.html en Chrome, Edge, Firefox o Safari.
Para publicarlo, suba la carpeta completa conservando la estructura de /assets.
